# Lotus RP

Abra index.html em um navegador moderno ou sirva esta pasta em qualquer hospedagem estática. HTML, CSS e JavaScript puros, sem compilação. As fontes do Google têm alternativas locais.

## Conteúdo e configuração

Os dados de clãs, províncias, política e comunidade estão no início de main.js. O HTML inclui uma cópia estática para leitura sem JavaScript. Ao alterar esses dados, atualize também essa cópia. Os textos de lore são ficcionais e editáveis. Configure os destinos oficiais de Discord, redes sociais, regras e status antes da divulgação pública. Os diálogos usam o elemento HTML dialog e devolvem o foco ao controle de origem.

## Trilha sonora

O arquivo `assets/moon-gate-empire.mp3` começa a tocar em loop ao abrir a página, se o navegador permitir e o visitante não tiver silenciado a trilha. Quando o navegador bloqueia o início automático, o primeiro clique ou toque inicia a música. Passe o mouse, use Tab ou toque no ícone para abrir a barra de volume. Toque fora do painel ou pressione Esc para recolher. O controle no canto inferior direito permite iniciar, silenciar e ajustar o volume. O volume inicial é 20%. O navegador guarda a preferência de volume e silêncio quando o armazenamento local está disponível.
